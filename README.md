# Verbs First

> Подробно: [продукт](docs/PRODUCT.md) · [архитектура](docs/ARCHITECTURE.md) · [план курса](docs/curriculum.md)

Греческий через глаголы — по принципам методики Д. Петрова.
React + TypeScript, Feature-Sliced Design, rspack, pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm build
pnpm typecheck
pnpm audio      # догенерировать озвучку для новых фраз (см. ниже)
```

## Архитектура (FSD)

Импорты идут только сверху вниз: `app → pages → widgets → features → entities → shared`.
Каждый слайс наружу отдаёт только свой `index.ts`.

```
src/
  app/                      инициализация: роутер, глобальные стили
  pages/
    home/                   список 16 уроков
    lesson/                 урок: один путь «Урок → Домашнее задание → Экзамен» и «Справочник»
  widgets/
    app-header/             шапка (логотип, навигация, переключатель темы)
    app-footer/             подвал
    verb-algorithm/         список глаголов урока + таблица выбранного глагола
    lesson-map/             карта урока: этапы на дорожке, медальоны за этапы
    lesson-path/            шаги этапа: список шагов, шаг, навигация
  features/
    conjugation-drill/      тренажёр «таблицы умножения» (model/useDrill + ui)
    pronounce/              кнопка 🔊 (готовый mp3, иначе греческий голос браузера)
    lesson-progress/        прогресс по шагам урока (localStorage)
    theme-switcher/         светлая/тёмная тема
    text-reading/           текст для чтения: разбор слов по клику, перевод, «найди глаголы», вопросы
    composition-check/      сочинение о себе: черновик + автоматический чек-лист по формам глаголов
    sentence-trainer/       фразы целиком: перевод с русского, диктант на слух, «скажи вслух» с самопроверкой
  entities/
    verb/                   тип Verb, данные спряжений, сборка фраз, анализатор текста, VerbTable 3×3
    lesson/                 тип Lesson, контент уроков, api getLesson / getLessonCatalog
  shared/
    lib/greek/              нормализация и сравнение ответов (мягкая проверка ударений)
    lib/speech/             озвучка: готовый mp3 по манифесту, иначе греческий голос браузера
    ui/                     Button, GreekKeyboard, SidebarLayout, Breadcrumbs, Callout, PrevNext
    config/routes.ts
```

## Стиль

Визуально — в духе учебника learn.javascript.ru: серый сайдбар 249px с навигацией,
колонка статьи до 800px, шрифт 18px, хлебные крошки, блоки-заметки (`Callout`),
плашки «предыдущий / следующий» (`PrevNext`), светлая и тёмная тема. Греческие мотивы — сдержанно:
эгейская палитра, заголовки Alegreya, меандр, ρ в венке в логотипе, лавровый венок за сданный экзамен.
Все цвета — CSS-переменные в `src/app/styles/global.css`.

## Контент

- Глаголы: `src/entities/verb/data/verbs.ts`. Формы хранятся явно (настоящее, аорист,
  совершенная основа для θα/να) — без генерации правилами.
- Уроки: `src/entities/lesson/data/lesson-XX.ts`, урок ссылается на глаголы по `id`.
- Новый урок = файл с данными + строка в `LESSONS` в `entities/lesson/api/lessonApi.ts`.
- Путь урока — массив `steps`, разбитый на этапы (`stage` у шага, названия и медальоны — `stages`).
  Этап — 3–5 коротких шагов про одно новое: время или тему. Таблицы в шагах `verbs` показывают
  только пройденное (`scope`). От этапов отходят необязательные ответвления (`branches`):
  шаг `story` («Любопытно» — этимология, факты, пара новых слов) и доп. практика. Типы шагов: `theory` (разделы грамматики по id),
  `verbs` (таблицы глаголов), `drill` (тренажёр по части таблицы + цель N верных ответов),
  `reading` (текст из `readings`), `phrases` (разговорная тема),
  `presentation` (сочинение о себе с чек-листом `checklist`).
- Тексты для чтения: `readings` в данных урока — предложения с переводом, словарик
  для неглагольных слов (ключ — слово без ударений, конечная ς → σ), вопросы.
  Глаголы урока словарь не требуют: их распознаёт `createAnalyzer` (время, лицо, отрицание).
- Чек-лист сочинения проверяет только формы глаголов урока — это подсказка, а не оценка.
  Проверка смысла и ошибок (ИИ/преподаватель) — когда появится бэкенд.
- Домашнее задание — массив `homework` из тех же шагов с полем `part` (части 1–4; `homeworkParts` — название и `after`: после какого этапа урока часть идёт на карте). Без «дней».
  Дополнительные типы шагов: `translate` (русский → греческий), `dictation` (на слух),
  `oral` (сказать вслух и сверить), `composition` (своё сочинение с чек-листом).
  В `items` у фразы `greek[0]` — эталон, остальные — тоже верные варианты
  (подлежащее-местоимение необязательно, его указывать не нужно).
  ДЗ урока 1: `src/entities/lesson/data/lesson-01-homework.ts`.
- Прогресс — один на весь путь урока (`progressKey.lesson`).
- План курса: `docs/curriculum.md`.

## Озвучка

Аудио генерируется заранее и лежит в `public/audio/` (mp3 + `manifest.json`: текст → файл).

```bash
python3 -m venv .venv && .venv/bin/pip install edge-tts   # один раз
pnpm audio                                                # только новые фразы
pnpm audio --force                                        # всё заново
```

- Скрипт `scripts/generate-audio.ts` собирает все тексты с кнопкой 🔊: формы глаголов
  во всех ячейках таблицы, примеры, фразы темы, предложения текстов и тексты целиком. Голос — `el-GR-NestorasNeural` (Athina на бесплатном доступе часто не отдаёт звук)
  (переменные `TTS_VOICE`, `TTS_RATE`).
- Синтез сейчас через `edge-tts` — бесплатные голоса Microsoft Edge, **неофициальный** доступ.
  Перед запуском для пользователей замените `synthesize()` на официальный Azure Speech:
  голос тот же, звучание не изменится.
- Для текста, которого нет в манифесте (свой текст ученика), используется греческий
  голос браузера; если его нет — кнопка показывает 🔇. Не греческим голосом не говорим.
