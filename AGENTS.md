# Verbs First — инструкции для агентов

Веб-сервис для изучения новогреческого через глаголы (принципы методики Д. Петрова).
React 19 + TypeScript + rspack + pnpm, Feature-Sliced Design, без бэкенда, GitHub Pages.

Прочитайте перед работой:
- [docs/PRODUCT.md](docs/PRODUCT.md) — что за продукт, методика, продуктовые принципы и решения.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — слои, модель данных, механизмы, как расширять.
- [docs/curriculum.md](docs/curriculum.md) — план 16 уроков.

## Правила

- Общение с владельцем и все тексты интерфейса — **на русском**.
- Соблюдать FSD: импорт только вниз по слоям и только через `index.ts` слайса.
- Перед коммитом: `pnpm typecheck` и `pnpm build`; `pnpm lint` (oxlint) запускается хуком сам — замечания чинить, а не отключать.
- Добавили или изменили греческий текст → `pnpm audio` и закоммитить mp3 + `public/audio/manifest.json`.
- Никаких абсолютных путей `'/…'` к ресурсам: сайт живёт под `/verbs-first/` (`process.env.BASE_URL`).
- Цвета — только CSS-переменные из `src/app/styles/global.css` (есть тёмная тема).
- Контент — только собственный: не копировать материалы и бренд Петрова.
  Греческие формы хранятся явно и требуют вычитки носителем — не генерировать правилами.
- Озвучка — только греческим голосом; не греческий синтез запрещён.
- Названия шагов не повторяют их тип (тип показывает чип).
- Любое греческое слово/фраза с переводом в интерфейсе можно добавить в карточки: выводить
  через `Word`/`wordIn`/`AddToCards` из `features/card-add` (в entities/widgets — через слот),
  набор — из `lessonDecks(lesson)` или свой. Исключение — упражнения (не подсказываем ответ).
- Фразы разбиваются на слова (`Phrase`): в карточку слово идёт **словарной формой** (глагол —
  начальная, существительное — им. п. ед. ч. с артиклем), не формой из текста. Новые слова и формы
  во фразах/текстах → `src/entities/dictionary/data/words.ts` (формы — явно), проверка: `pnpm lexicon:check`.
- Последний шаг урока — `{ kind: 'exam' }` («Итог урока N»): задания собираются сами из данных урока, поэтому нужны фразы в шагах, `vocabulary` и вопросы к текстам.
- Экзамен — отдельный тип со строгими правилами; тренажёры — практика. Не смешивать.
- ДЗ делится на части (`part` + `homeworkParts`), не на дни: никаких сроков в интерфейсе.
- Новый урок: заполнить и `vocabulary` (слова для карточек, существительные — с артиклем).
- Изменение зависимостей → закоммитить `pnpm-lock.yaml` (CI ставит `--frozen-lockfile`).
- Пуш в `main` сразу деплоит сайт.
- PWA: меняете кэширование в `public/sw.js` — поднимите `VERSION`; иконки приложения — из `public/icons/*.svg`.
