# Verbs First — инструкции для агентов

Веб-сервис для изучения новогреческого через глаголы (принципы методики Д. Петрова).
React 19 + TypeScript + rspack + pnpm, Feature-Sliced Design, без бэкенда, GitHub Pages.

Прочитайте перед работой:
- [docs/PRODUCT.md](docs/PRODUCT.md) — что за продукт, методика, продуктовые принципы и решения.
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — слои, модель данных, механизмы, как расширять.
- [docs/curriculum.md](docs/curriculum.md) — план 16 уроков.

## Правила

- Общение с владельцем и все тексты интерфейса — **на русском**.
- Соблюдать FSD: импорт только вниз по слоям и только через `index.ts` слайса.
- Перед коммитом: `pnpm typecheck` и `pnpm build`; `pnpm lint` (oxlint) запускается хуком сам — замечания чинить, а не отключать.
- Добавили или изменили греческий текст → `pnpm audio` и закоммитить mp3 + `public/audio/manifest.json`.
- Никаких абсолютных путей `'/…'` к ресурсам: сайт живёт под `/verbs-first/` (`process.env.BASE_URL`).
- Цвета — только CSS-переменные из `src/app/styles/global.css` (есть тёмная тема).
- Контент — только собственный: не копировать материалы и бренд Петрова.
  Греческие формы хранятся явно и требуют вычитки носителем — не генерировать правилами.
- **Переводы — близко к греческому, слово в слово, где русский это позволяет.** Ученик сверяет перевод
  со словами: каждое русское слово должно узнаваться в греческом. Не заменять синонимом или антонимом
  («δεν… πολύ» — «не много», а не «мало»; ψάχνω — «искать», а не «осматривать»), не менять конструкцию
  (στη δουλειά — «на работе», а не «за работой»), не терять слова (της — «своей», «её»). Порядок слов —
  как в греческом, если по-русски звучит нормально. Красивый литературный перевод — нет; естественный и узнаваемый — да.
  Если без перестройки по-русски не сказать — перевести естественно, а разницу объяснить в шаге или в справочнике.
  Касается всего: фраз уроков, текстов, Истории, примеров справочника, вариантов в заданиях.
- Озвучка — только греческим голосом; не греческий синтез запрещён.
- Названия шагов не повторяют их тип (тип показывает чип).
- Любое греческое слово/фраза с переводом в интерфейсе можно добавить в карточки: выводить
  через `Word`/`wordIn`/`AddToCards` из `features/card-add` (в entities/widgets — через слот),
  набор — из `lessonDecks(lesson)` или свой. Исключение — упражнения (не подсказываем ответ).
- Фразы разбиваются на слова (`Phrase`): в карточку слово идёт **словарной формой** (глагол —
  начальная, существительное — им. п. ед. ч. с артиклем), не формой из текста. Новые слова и формы
  во фразах/текстах → `src/entities/dictionary/data/words.ts` (формы — явно), проверка: `pnpm lexicon:check`.
- **У каждого греческого слова на сайте — словарная форма и перевод.** Добавили любой греческий текст
  (урок, ответвление, курс чтения, тексты, примеры) — каждое слово в нём должно открываться с переводом,
  без «впишите сами». Новый источник греческого текста (новый вид шага, новые данные) — сразу добавить
  в `scripts/lexicon-coverage.ts`; `pnpm lexicon:check` должен показывать 0 слов без словарной формы.
- Урок делится на этапы (`stage` у каждого шага + `stages` с `award`): по 3–5 коротких шагов, по одному новому куску;
  в шагах `verbs` задавайте `scope` — таблица показывает только уже пройденные времена и формы.
- Ответвления (`branches`) — необязательное: шаг `story` (этимология, факты — только проверенные, 1–2 новых слова
  в `words.ts`) и доп. тренажёр. В экзамен и медальоны не входят.
- Последний шаг урока — `{ kind: 'exam' }` («Итог урока N»): задания собираются сами из данных урока, поэтому нужны фразы в шагах, `vocabulary` и вопросы к текстам.
- Экзамен — отдельный тип со строгими правилами; тренажёры — практика. Не смешивать.
- ДЗ делится на части (`part` + `homeworkParts` с `after`), не на дни: никаких сроков в интерфейсе.
  Часть идёт сразу после своей темы и использует только пройденное к этому месту.
- Новый урок: заполнить и `vocabulary` (слова для карточек, существительные — с артиклем).
- Раздел «Тексты» (`entities/library/data/texts.ts`): у текста `level` — после какого урока он по силам;
  глаголы — только из пройденных к этому уроку, остальные слова — в словарь, факты — только проверенные.
- Раздел «История» (`entities/story/data/chapter-NN.ts`, сюжет — `docs/story/README.md`, картинки мест — `docs/story/illustrations.md`): глава N — после урока N,
  глаголы и грамматика только из уроков 1…N; ответ задачи не должен быть виден в объяснении или в тексте куска.
  **Уровни глав** (лёгкий · средний · сложный): текст один, задания разные — `STORY_LEVELS` в `entities/story/model/types.ts`.
  У каждого пропуска — `options` для лёгкого (формы явно). **Матрица:** задание главы N на уровне L опирается только
  на объяснённое в главах 1…N на уровнях не выше L — цепочка на лёгком самодостаточна. Пройденное на сложном
  засчитывается и на лёгком; следующая глава открывается, когда текущая пройдена хотя бы на лёгком.
  Второй герой — кот Ερμής: ответвления глав (факты, мифы, этимология) — его истории; в тайну он не вмешивается.
- Справочник (`entities/grammar/data`, страница `/grammar`): темы → правила с адресом `/grammar/<тема>#<правило>`.
  Объяснения грамматики пишутся **один раз — в справочнике**; уроки, тексты и окна слов ссылаются на правило.
  Готовите урок или текст — сверьтесь: новое явление, которого справочник не покрывает, → сначала дописать правило.
  Греческий в справочнике проходит `pnpm lexicon:check` и `pnpm audio` (примеры), как и остальной контент.
- «Почему так?» в окне слова: у глаголов — само (время, лицо → правило); у остальных форм — явное `why` в словаре
  (`{ форма: { note, rule: 'тема#правило' } }`, частые — `dictionary/data/notes.ts`). Новые формы в тексте (падеж,
  мн. ч., согласование, слияние σε + артикль) → добавьте и `why`; `pnpm lexicon:check` проверяет, что правило существует.
- Урок 0 (курс чтения, `entities/alphabet/data/course.ts`): в словах этапа — только пройденные буквы
  и сочетания, проверка: `pnpm reading:check`.
- Изменение зависимостей → закоммитить `pnpm-lock.yaml` (CI ставит `--frozen-lockfile`).
- Пуш в `main` сразу деплоит сайт.
- PWA: меняете кэширование в `public/sw.js` — поднимите `VERSION`; иконки приложения — из `public/icons/*.svg`.
