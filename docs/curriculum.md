# Программа курса: греческий язык, 16 уроков

Структура по принципам методики Д. Петрова (глагол как основа, «таблица умножения»,
мини-презентации о себе, «свобода прежде правильности»). Контент — собственный.

## Шаблон урока

Каждый урок состоит из 4 блоков:

1. **Грамматика** — 1–2 темы.
2. **Разговорная тема** — лексика + мини-презентация «о себе».
3. **Алгоритм глагола** — 8 глаголов, у каждого карточка-таблица:
   3 времени (настоящее / прошедшее-аорист / будущее θα + совершенная основа)
   × 3 формы (утверждение / вопрос `;` / отрицание `δεν`) × 6 лиц.
4. **Упражнения** + тренажёр (интервальное повторение по ячейкам таблицы).

Итого: 128 глаголов + είμαι и έχω в грамматических блоках.

## Урок 0. Алфавит и чтение

> Сделан отдельной частью «Алфавит» (`/alphabet`), вне нумерации уроков.

- 24 буквы, ударение (τόνος), сочетания: ου, αι, ει/οι/υ/η → [и], μπ, ντ, γκ, τσ, τζ, αυ/ευ.
- Греческая раскладка на клавиатуре, ввод ударений.
- Чтение слов, которые уже понятны: καφές, ταξί, μουσική, τηλέφωνο.

## Урок 1. Алгоритм греческого глагола

**Грамматика:** 6 лиц, местоимения опускаются; полная таблица 3×3 сразу;
вопрос интонацией и `;`; отрицание `δεν`; образование аориста (основа + σ/ψ/ξ, приращение έ-);
глагол **είμαι** (ήμουν, θα είμαι).
**Тема:** знакомство, этикет (Γεια σας, Με λένε…, Από πού είστε;).

| Глагол | Значение | Аорист | Будущее |
|---|---|---|---|
| δουλεύω | работать | δούλεψα | θα δουλέψω |
| γράφω | писать | έγραψα | θα γράψω |
| διαβάζω | читать, учить | διάβασα | θα διαβάσω |
| ακούω | слушать, слышать | άκουσα | θα ακούσω |
| ψάχνω | искать | έψαξα | θα ψάξω |
| μαγειρεύω | готовить | μαγείρεψα | θα μαγειρέψω |
| ταξιδεύω | путешествовать | ταξίδεψα | θα ταξιδέψω |
| αγοράζω | покупать | αγόρασα | θα αγοράσω |

## Урок 2. Глаголы с особым прошедшим

глагол **έχω** (είχα, θα έχω).
**Тема:** профессии (Τι δουλειά κάνετε; Είμαι…).

| Глагол | Значение | Аорист | Будущее |
|---|---|---|---|
| κάνω | делать | έκανα | θα κάνω |
| μένω | жить, оставаться | έμεινα | θα μείνω |
| ξέρω | знать | ήξερα* | θα ξέρω |
| μαθαίνω | узнавать, учить | έμαθα | θα μάθω |
| καταλαβαίνω | понимать | κατάλαβα | θα καταλάβω |

## Урок 4. Хочу / могу / надо + να

винительный падеж (τον, την, το).
**Тема:** кафе и таверна (Θα ήθελα έναν καφέ. Μπορώ να έχω τον λογαριασμό;).

| Глагол | Значение | Аорист | Будущее |
|---|---|---|---|
| θέλω | хотеть | ήθελα / θέλησα | θα θέλω |
| μπορώ | мочь | μπόρεσα | θα μπορέσω |
| πρέπει | надо (безл.) | έπρεπε | θα πρέπει |
