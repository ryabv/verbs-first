# Находки

Каждая глава Истории заканчивается находкой — предметом, который двигает тайну тёти: письмо, фигурка, тетрадь,
рисунок, ключ, фотография, кассета. Находка — награда за дочитанную главу и якорь сюжета: по полке находок видно,
как далеко Анна продвинулась.

## Как выглядит

Находка — **трёхмерный предмет**, его можно взять «в руки»: тащить — вертится во все стороны, отпустить —
докручивается по инерции, в покое — медленно поворачивается и покачивается в тёплом сиянии.

| Где | Что видит ученик |
|---|---|
| **Конец главы** (дочитал) | Блок «Находка главы»: предмет поднимается снизу с вращением, замедляется, вспыхивает волна света; рядом — название и что это. |
| **Карта → «Находки»** | Полка: найденные предметы — 3D-миниатюры в ячейках, ненайденные — «?». Нажатие на предмет — окно с ним крупно (вертеть рукой), название, текст, глава. |

Без WebGL (или пока грузится) — значок-силуэт предмета. «Уменьшить движение» в системе — без вылета и вспышки,
предмет просто стоит; вертеть рукой можно.

## Предметы

Модели собираются в коде (three.js) по типу предмета — без внешних файлов; надписи на бумаге — по-гречески,
как в тексте главы (слова — в словаре).

| Тип (`icon`) | Предмет |
|---|---|
| `letter` | конверт с сургучной печатью, на нём рукой тёти «Για την Άννα» |
| `figurine` | каменная фигурка женщины с раскрытыми руками (зелёно-голубой камень) |
| `notebook` | тетрадь тёти в кожаной обложке, с резинкой |
| `map` | вырванный лист тетради: рисунок фигурки, «χαλκός», внизу «Λευκωσία» |
| `photo` | старая фотография с белой рамкой |
| `key` | старинный ключ |
| `tape` | аудиокассета с подписью |

## Правила

- У каждой главы — одна находка (`find` в данных главы); «Находки N из M» считаются по главам с находкой.
- Новый тип предмета — сначала строка в таблице выше, потом модель.
- Надписи на предмете не подсказывают ответы заданий главы.
