# Ивенты и мини-игры

> Статус: **план** — фаза 4 (ивенты, мини-игры без голоса); голосовые игры — фаза 8 ([roadmap.md](roadmap.md)).

## Зачем

Новизна и связь с настоящей Грецией: праздник идёт в Греции — он идёт и в приложении. Ивент — повод
вернуться, выучить тематические слова и поиграть в то, чего нет в Кампании.

## Что такое ивент

| Поле | Пример |
|---|---|
| Тема | Πάσχα — Пасха |
| Окно дат | 2 недели вокруг даты праздника (дата Пасхи — своя на каждый год) |
| Рассказ кота | что за праздник, обычаи, 1–2 фразы — по правилам ответвлений (факты проверенные) |
| Слова | 8–15 тематических слов → набор карточек «Ивент · Пасха» |
| Мини-игры | 2–3 игры на этих словах |
| Награда | значок ивента в рюкзак |

Слова ивента — исключение из «только пройденное»: тематическая лексика новая, но **глаголы и грамматика**
в заданиях — только пройденные (по прогрессу Кампании).

**Календарь ивентов (черновик):** Απόκριες (карнавал), 25 марта, Πάσχα, 15 августа, 28 октября (Ημέρα του Όχι),
именины популярных имён, Χριστούγεννα. Каждый ивент можно повторно открыть в следующем году.

## Мини-игры

Мини-игра — **оболочка** (механика, графика) + **тип задания** из [tasks.md](tasks.md). Новая игра на старом
типе не требует новой проверки ответов.

| Игра | Механика | Тип задания |
|---|---|---|
| **Дорога** | машина едет, на развилках говорите «αριστερά» / «δεξιά» / «ευθεία» | `voice` (или кнопки) |
| **Рынок** | продавец называет товар — нажмите нужный на прилавке | `listen` |
| **Открытка** | соберите поздравление из плиток | `translate` (плитки) |
| **Порядок** | расставьте реплики диалога по порядку | `order` |

## Голосовые игры

### Технология

Свой ИИ не нужен: в браузере есть **Web Speech API** (`SpeechRecognition`, язык `el-GR`).
Ограничения, которые определяют дизайн игры:

| Ограничение | Следствие для дизайна |
|---|---|
| Chrome отправляет звук на серверы Google, Safari — через Siri; Firefox распознавание не поддерживает | нужна сеть; везде — запасной вариант с кнопками; предупреждение о микрофоне |
| Задержка ~0,5–1,5 с | команду объявляем заранее: развилка видна за 3–4 секунды; на лёгком — медленнее |
| Короткие слова распознаются нестабильно | список засчитываемых вариантов (`accepted`) и несколько гипотез распознавания; команды подбирать различимые |
| Нужно разрешение на микрофон | спрашиваем по кнопке «Играть голосом», не при открытии страницы |

Если понадобится офлайн и надёжность — локальная модель поиска ключевых слов (распознаёт только свой короткий
список команд). Это следующий шаг после прототипа, не первый.

### Прототип (первый шаг)

Страница-песочница: кнопка микрофона, произносим команды, видим все гипотезы распознавания и время отклика.
Проверить на телефоне и компьютере владельца (Chrome, Safari) команды «αριστερά», «δεξιά», «ευθεία», «σταμάτα».
По результатам — список `accepted` и решение, годится ли Web Speech API.

### «Дорога» — эскиз

- Вид сверху, машина едет сама. Перед развилкой — знак-стрелка (средний уровень) или подпись по-гречески (лёгкий).
- Ученик говорит команду; распознано верно — машина поворачивает; неверно или не успел — проезжает мимо, круг
  удлиняется (не «проигрыш»).
- Сложный: команда приходит по-русски («налево!») или на слух от пассажира.
- В конце — сколько поворотов с первого раза; слова игры — в карточки.
