# Главная, Учёба, Профиль

> Статус: **готово** (ноябрь 2026).

## Навигация

Три раздела верхнего уровня: **Главная · Учёба · Профиль** (на телефоне — нижняя панель: значок с подписью,
активный — цветом раздела; на компьютере — шапка).

- **Главная** (`/`) — прогресс по зонам учёбы и вход в каждую одним нажатием.
- **Учёба** — четыре зоны: **История** (карта острова, `/island`), **Ежедневные** (`/today`), **Карточки** (`/cards`),
  **Справочник** (`/grammar`). «Учёба» в меню на компьютере открывает зону, где ученик был последним
  (по умолчанию — Историю), а по наведению показывает меню из четырёх зон; на телефоне — раскрывает над собой веер из
  четырёх зон полукругом (180°), текущая — залита; «Учёба» становится ✕, нажатие мимо или Esc — закрывают.
  Отдельного переключателя зон на страницах нет. Внутри зоны (глава, шаг, день, тема справочника) назад ведёт стрелка.
- **Профиль** (`/profile`) — коллекция всего собранного: находки, сосуды, медальоны ([collection.md](collection.md));
  под ней настройки — тема («Как в системе / Светлая / Тёмная»); дальше — серия, данные, синхронизация.

## Главная

Задача — зайти и захотеть учиться: место из Истории, живое приветствие, понятный «сегодняшний» объём.
Без «рекомендаций», что делать первым: ученик выбирает сам.

1. **Шапка** — картинка места текущей главы во весь экран (медленно «дышит»; у главы без картинки — место последней
   главы с картинкой). На ней: приветствие по-гречески по времени суток (Καλημέρα / Καλησπέρα / Καληνύχτα; перевод — по нажатию, как у слов),
   под ним **пословица дня** — греческий (слова нажимаются с переводом и «в карточки», набор «С Главной»), перевод
   слово в слово, «послушать», «смысл» (всплывает поверх: что значит, русский аналог). Пословицы — `entities/proverb`,
   по одной в день по кругу. Серия «N дней подряд» с венком, если ежедневные закрыты подряд.
2. **Сегодня** — первым, ради привычки. Каждая зона — одна строка: картинка · заголовок · круглая кнопка справа.
   - **Ежедневные** (пока день не закрыт — терракотовая кромка): сосуд месяца покачивается, залит по найденным
     черепкам; «Черепок дня ждёт» / «Решено N из M» / «Черепок найден!»; неделя — кружки с буквой дня (олива с галочкой —
     закрыт, кольцо — начат, рамка — сегодня). Кнопка ▶ с кольцом прогресса дня и подписью «N мин» / «дальше» / «в музей»;
     пока день не начат — мягко пульсирует.
   - **Карточки:** стопка, на верхней — слово, которое ждёт первым; «N слов ждут» / «новые»; полоска «выучено N из M»;
     кнопка с числом слов — «повторить» / «учить».
3. **История** — пергамент главы: эпоха и глава, греческое название и перевод, завязка (`intro`), «прочитано N из M»,
   кнопка «Читать / Продолжить / Закрепить главу N», «Пройдено глав».
   **Новичок** (глава 1 не начата, пролог не пройден) — вместо главы пергамент пролога: «Пролог · по желанию»,
   «Греческий алфавит», «Ещё не читаете — начните с алфавита», кнопка «Учить алфавит» (начат — полоска и «Продолжить
   алфавит») и ссылка «Уже читаю по-гречески — к главе 1». Начал главу 1 — дальше обычная карточка главы. На странице
   главы 1, пока пролог не пройден, — плашка «Ещё не читаете по-гречески? Начните с пролога» (начат — «Алфавит: пройдено
   N из 47. Продолжить пролог») (решение
   владельца, 2026-11-26: карта больше не главная, и без этого новичок не узнаёт о прологе).

Подписи разделов — двери: «Ежедневные →» и «Карточки →» в карточках, «История · Карта острова →» над главой.

На компьютере всё в один экран: картинка — фоном, слева «Сегодня», справа «История».

Справочник на главной не показывается — у него нет прогресса.

## Карточки в учёбе

Карточки — не отдельный инструмент, а память всех зон:

1. **Слова главы — в карточки сами, по мере чтения.** Прочитал шаг главы — словарные формы слов его куска добавляются
   в набор «Из истории»; открытая, но не начатая глава ничего не добавляет (решение владельца, 2026-11-27). Кнопка «Слова главы — в карточки» больше не нужна: в конце главы — «Слова главы добавлены в карточки».
2. **Ошибки дня — в карточки сами.** Показали ответ в ежедневных — слова этого задания добавляются в набор
   «Из ежедневных»; в итоге дня — «Слова из ошибок добавлены в карточки».
3. **Карточки — часть дня.** Часть дня «Слова» набирается из карточек: что пора повторить и пара новых слов
   (решение владельца, 2026-11-27, отменяет строку «Карточки: повторить N» в оглавлении; [cards.md](cards.md)).
