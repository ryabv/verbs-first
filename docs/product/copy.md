# Тексты интерфейса

Одни и те же слова для одних и тех же действий во всём приложении. Новая кнопка или подпись — сначала
найдите её здесь; нет — добавьте сюда вместе с кодом.

> Статус: черновик. Словарь собран из текущего интерфейса (ноябрь 2026); расхождения отмечены.

## Голос

- По-русски, на **«вы»**, коротко и по-человечески. Как спокойный учитель, не как игра с конфетти.
- Ошибка — не провал: «Не совсем», «Почти!», а не «Неправильно» и не красные кресты на весь экран.
- Без восклицаний подряд. «!» — только в коротких похвалах: «Верно!», «Готово!».
- Греческое в тексте — без перевода в скобках, если оно нажимается (перевод — по нажатию). Иначе — «ελπίδα» — «надежда».
- Имена героев по-гречески: Ερμής, Ελένη, Ρούλα. В заголовках ЗАГЛАВНЫМИ — без ударений (ставить `lang="el"`).
- Без сроков и давления в Кампании: никаких «день 1», «осталось 3 дня». В Ежедневных и Ивентах даты — суть механики,
  но и там без укоров: не «Вы пропустили 5 дней», а «Можно догнать: 5 дней».
- Пол ученика неизвестен: «Сказал(а)», «Ошибся(лась)» — или безличные формы, где можно.

| Действие | Текст | Где | Примечание |
|---|---|---|---|
| Проверить ответ | «Проверить» | все задания с вводом и выбором | |
| Сдаться и увидеть ответ | «Показать ответ» | все задания, кроме экзамена | в шапке блока «Задание» |
| Следующий шаг | «Дальше» | шаги, задания | стрелка после текста |
| Предыдущий шаг | «Назад» | шаги | стрелка перед текстом |
| Начать задание с режимом | «Начать» | `tap`, экзамен («Начать экзамен»), карточки | |

| Подсказка по запросу | «Подсказка» | `form`, `translate` | скрыта до нажатия |
| Озвучить | значок динамика | везде | подпись для экранного диктора: «Прослушать» |

## Отклики

| Ситуация | Текст |
|---|---|
| Верно | «Верно!» |
| Верно, но ударение не там | «Почти!» + «Проверьте ударение» |
| Другой верный вариант | «Тоже верно» + эталон |
| Неверно | «Не совсем» (+ «Показать ответ» доступен) |
| Всё выполнено | «Готово!» |
| В карточках на сегодня всё | «На сегодня всё!» + когда следующее повторение + «Потренироваться ещё» |

## Уровни

«Лёгкий» · «Средний» · «Сложный». Описание для ученика (переключатель):
- Лёгкий — «выбираете ответ из вариантов»;
- Средний — «вписываете сами, с подсказкой»;
- Сложный — «вписываете без подсказок, реплики — на слух».

## Награды (план для новых режимов)

| Что | Текст |
|---|---|
| День закрыт | «День закрыт» |
| День закрыт без показанных ответов | «День закрыт чисто» (звезда) |
| Месяц закрыт | «Кубок за ноябрь» (месяц — в именительном: «Кубок · Ноябрь 2026») |
| Можно догнать | «Можно догнать: N дней» |
| Ивент | «Ивент закончится через N дней» — единственное место с обратным отсчётом |

## Расхождения в текущем интерфейсе

- В уроках есть «Предыдущий шаг» / «Следующий шаг», в Истории — «Назад» / «Дальше». Предложение: везде «Назад» / «Дальше».
- «Ещё раз», «Ещё сессия», «Пройти ещё раз», «Потренироваться ещё» — четыре формы повтора. Свести к двум:
  «Ещё раз» (то же задание) и «Потренироваться ещё» (новая порция).
