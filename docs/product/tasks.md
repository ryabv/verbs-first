# Типы заданий

Каталог всех типов заданий приложения и продуктовая матрица. Это контракт для контента: глава, день или
ивент собираются только из типов этого каталога. Новый тип — сначала карточка здесь.

> Статус: черновик. Инвентаризация сделана по коду (ноябрь 2026). Сейчас одни и те же по смыслу задания
> реализованы по отдельности в разных разделах (Истории, уроках, алфавите, карточках, экзамене).
> Каталог сводит их в **семейства**: у семейства один id и одна карточка, а места реализации перечислены.
> Это задаёт будущий реестр типов в коде.

## Главная матрица: 4 навыка × 3 уровня

Задания покрывают **четыре области языка**: чтение, слушание, письмо, говорение. Каждая — на трёх уровнях.
Правило лестницы одно для всех навыков:

- **Лёгкий — узнать:** выбрать из вариантов, собрать из готового, повторить за образцом.
- **Средний — вспомнить с опорой:** сделать самому, но рядом подсказка (начальная форма, текст перед глазами, перевод слов).
- **Сложный — без опоры:** сделать самому, видя только смысл по-русски; звук — понять без текста.

| Навык | Лёгкий | Средний | Сложный |
|---|---|---|---|
| **Чтение** — понять написанное | `choose`: выбрать перевод фразы или значение слова ✓ · `tap` с числом нужных слов ○ | `text`: вопросы к тексту, слова открываются с переводом ✓ · `tap` без числа ✓ · `order`: реплики по порядку ○ | `text` без перевода фраз и слов ○ |
| **Слушание** — понять услышанное | `listen`: услышать и выбрать написание ✓ | `listen`: услышать и выбрать смысл, текст скрыт ✓ | `dictation`: записать услышанное ✓ · `text` на слух: вопросы к прослушанному ○ |
| **Письмо** — написать самому | `gap`: выбрать форму в пропуск ✓ · `tiles`: собрать фразу из плиток ○ | `gap`, `form`, `translate` с подсказкой ✓ | `gap`, `form`, `translate` без подсказки ✓ · `compose`: сочинение ✓ |
| **Говорение** — сказать самому | `shadow`: послушать и повторить ○ | `readaloud`: прочитать фразу вслух ○ | `oral`: сказать по-гречески по русской фразе ✓ (самопроверка) · `voice`: команда в игре ○ |

✓ — есть на сайте (где-нибудь), ○ — нужно сделать. Говорение — **фаза 8** ([roadmap.md](roadmap.md)): до неё в Кампании и
Ежедневных задания только трёх навыков. Слабее всего покрыты **говорение** (есть только самопроверка) и
**сложное чтение и слушание** (понимание связного текста без опор).

**Говорение и распознавание речи.** `shadow`, `readaloud`, `oral` сначала работают с самопроверкой (ученик слышит образец и
сам отмечает результат). Когда прототип распознавания подтвердит, что браузер понимает греческий (см. [events.md](events.md)),
проверка становится автоматической там, где распознавание доступно, а самопроверка остаётся запасной.

**Матрица уровней Кампании:** задание главы N на уровне L опирается только на объяснённое в главах 1…N на уровнях не выше L.
Для Ежедневных и Ивентов — то же, по пройденным главам.

## Задания в Кампании

Историю читают и слушают, не застревая. Задания в Кампании — трёх видов:

| Вид | Где | Типы и уровень | Блокирует? |
|---|---|---|---|
| **Вопрос на понимание** | внутри чтения, в 1–2 шагах из трёх | `choose`, `listen`, `tap` — всегда лёгкий, ~5 секунд | нет: ошибка — подсказка, сюжет идёт дальше |
| **Закрепление главы** | по умолчанию после главы (можно пропустить) | все четыре навыка, 8–12 заданий на выбранном уровне | нет |
| **Порог эпохи** | между эпохами | все главы эпохи закреплены хотя бы на лёгком | да — единственное место |

Подробно — [docs/story/README.md](../story/README.md#чтение-и-закрепление).

Кр — Карточки. ✓ — уже используется, ○ — подходит, план, — — не подходит.

## Проверка ответов

Общая для всех типов (`shared/lib/greek`):
- греческий: без учёта регистра и конечной `ς/σ`; варианты через `/`; артикль у существительного необязателен;
- ошибка только в ударении — **«Почти!»**: засчитывается с пометкой (кроме экзамена — там это ошибка);
- русский: любое из значений через `,`/`;`, скобки игнорируются, одна опечатка в слове от 5 букв — «почти».

## Карточки типов

Формат карточки:
- **Ученик видит / делает** — экран глазами ученика.
- **Данные** — что пишет автор контента. Всё греческое — явно, правилами не генерируется.
- **Проверка** — когда «верно», что при ошибке.
- **Уровни** — чем отличаются.
- **Правила контента** — что нельзя (обычно: ответ не должен быть виден рядом).
- **Тексты** — кнопки и подписи (дословно, см. [copy.md](copy.md)).
- **Реализация** — где в коде сейчас.

### `gap` — Пропуск в тексте

- **Ученик видит:** предложение главы с пропуском на месте слова — в блоке «Закрепить» (текст главы остаётся целым)
  и поле (или варианты). Сейчас на сайте пропуск стоит прямо в тексте и держит «Дальше» — это меняется
  (см. [docs/story/README.md](../story/README.md#чтение-и-закрепление)).
- **Данные:** `sentence` (номер предложения), `word` (верная форма, как в тексте), `hint` («αγοράζω, она,
  прошедшее»), `options` (варианты для лёгкого, среди них `word`, формы явно), `meaning?` (смысл по-русски для
  сложного; у глагола берётся из разбора сам). В одном задании может быть несколько пропусков.
- **Проверка:** общая; ударение — «Почти!». Верно — слово встаёт в текст.
- **Уровни:** Л — выбрать из `options`; С — вписать, рядом `hint`; Сл — вписать, рядом только `«смысл»`.
- **Правила контента:** ответ не встречается в объяснении шага и в видимом тексте (в том числе в прошлых кусках
  той же формой). Варианты лёгкого — правдоподобные: то же слово в других формах.
- **Тексты:** «Проверить», «Показать ответ».
- **Реализация:** `pages/story/ui/StoryTask.tsx` (`GapChoice`, `GapTask`).

### `form` — Форма глагола

- **Ученик видит:** «Мы не читали» → пишет `Δεν διαβάσαμε`. Одна клетка «таблицы умножения».
- **Данные:** не пишутся — собираются из словаря глаголов (`buildGreek`/`buildRussian`) по `scope`:
  глаголы, времена, формы (утверждение / вопрос / отрицание), лица.
- **Проверка:** общая; местоимение необязательно. Ошибочная фраза возвращается через пару заданий.
- **Уровни (план):** Л — выбрать из 4 форм того же глагола; С — вписать, начальная форма по кнопке «Подсказка»;
  Сл — вписать без подсказки.
- **Правила контента:** только глаголы и времена, пройденные к этому месту.
- **Реализация:** `features/conjugation-drill` (уроки, без уровней), задания `write` в `features/exam`.
- **Для Ежедневных:** главный кандидат на «автоматизм» — генерируется бесконечно и уже вычитан (формы из словаря).

### `tap` — Нажать слова в тексте

- **Ученик видит:** условие («Нажмите все глаголы в будущем времени») и кнопку «Начать». После «Начать» слова
  текущего куска становятся кнопками; до этого текст работает как обычно (слово открывает перевод).
- **Данные:** `prompt`, `answer` (формы слов, как в тексте).
- **Проверка:** выбраны все нужные и ни одного лишнего. После проверки верные выбранные — зелёные, лишние — красные.
  Нажатие на выбранное слово снимает выбор.
- **Уровни:** пока одинаковы. Идея: Л — число нужных слов известно («3 глагола»), Сл — неизвестно.
- **Тексты:** «Начать», «Слова в тексте станут кнопками — нажимайте нужные.», «Проверить», «Снять выбор».
- **Реализация:** Story `tap` (`StoryTask` + `StoryText`), уроки — `findTense` в `features/text-reading`.

### `choose` — Выбрать вариант

- **Ученик видит:** вопрос и 3–4 варианта: перевод фразы, верная реплика, значение слова, ответ на вопрос к тексту.
- **Данные:** `prompt`, `options`, `answer` (индекс). Варианты — одного вида и длины, без «очевидно лишнего».
- **Проверка:** выбор = ответ. Ошибка — подсветка, можно выбрать снова (кроме экзамена).
- **Уровни:** пока одинаковы.
- **Реализация:** Story `choose`, алфавит `choice` (`ChoiceQuiz`), карточки `recall`/`recognize`, экзамен `choice`,
  вопросы к текстам `ReadingView`.

### `listen` — Услышать и выбрать

- **Ученик видит:** кнопку озвучки; текст реплики скрыт (в Истории — размыт) до ответа.
- **Данные:** `audio` (греческий текст, озвучка из манифеста), `options`, `answer`.
- **Проверка:** как `choose`; на сложном — как `dictation`.
- **Уровни:** Л, С — выбрать; Сл — записать услышанное.
- **Реализация:** Story `choose` с `audio` (+ `Dictation` на сложном), алфавит «Услышь и выбери», карточки `listen`.

### `translate` — Перевести фразу

- **Ученик видит:** русскую фразу, пишет греческую. Греческая клавиатура на телефоне свёрнута.
- **Данные:** `russian`, `greek[]` (первый — эталон, остальные тоже верны).
- **Проверка:** общая; местоимение необязательно.
- **Уровни (план):** Л — собрать из плиток-слов (+1–2 лишних); С — вписать, глагол по кнопке «Подсказка»; Сл — вписать.
- **Реализация:** `features/sentence-trainer` (`translate`), карточки `write`, экзамен `write`.

### `dictation` — Диктант

- **Ученик видит:** кнопку озвучки; пишет услышанное.
- **Данные:** `greek[]`, `russian` (показать после ответа).
- **Проверка:** общая. На экзамене — не больше 2 прослушиваний.
- **Уровни (план):** Л — собрать из плиток; С — вписать, можно слушать сколько угодно, медленная скорость; Сл — вписать, 2 прослушивания.
- **Реализация:** `features/sentence-trainer` (`dictation`), Story `Dictation`, экзамен.

### `oral` — Сказать вслух

- **Ученик видит:** русскую фразу; говорит по-гречески; открывает ответ с озвучкой; сам отмечает «Сказал(а) верно» или «Ошибся(лась) — повторить позже».
- **Данные:** как `translate`.
- **Проверка:** самопроверка (честно ответить себе). В экзамен не входит.
- **Развитие:** с распознаванием речи (см. `voice`) — опционально проверять автоматически, самопроверка остаётся запасной.
- **Реализация:** `features/sentence-trainer` (`oral`), карточки `flip`.

### `voice` — Голосовая команда (план)

- **Ученик видит:** игровую ситуацию (машина подъезжает к развилке) и говорит команду по-гречески.
- **Данные:** `accepted[]` — все засчитываемые варианты распознанного текста («αριστερά», «αριστερα», «στα αριστερά»),
  `fallback` — кнопки с теми же командами.
- **Проверка:** распознанный текст (несколько гипотез) нормализуется и сравнивается с `accepted`. Нет микрофона,
  браузер не умеет распознавать, нет сети — тот же экран с кнопками.
- **Уровни:** Л — команда подписана на экране; С — только картинка-стрелка; Сл — команда по-русски или на слух.
- **Правила контента:** короткие, хорошо различимые команды; заранее проверить, как их распознаёт браузер.
- **Реализация:** нет. Подробности и ограничения — [events.md](events.md).

### `build` — Собрать слово из плиток

- **Ученик видит:** звук и чтение слова, плитки-буквы, среди них ловушки (три «и», σ/ς).
- **Данные:** слово, ловушки.
- **Проверка:** порядок плиток = слово. После двух неудачных попыток — ответ.
- **Реализация:** алфавит `build` (`BuildWord`). Кандидат на основу «плиток» для лёгкого `translate`/`dictation`.

### `read` — Прочитать и проверить себя

- **Ученик видит:** слоги или «лесенку слов»; читает сам, нажимает — слышит и видит чтение.
- **Проверка:** без проверки, самоконтроль.
- **Реализация:** алфавит `syllables` (`SyllableGrid`), `ladder` (`WordLadder`).

### `text` — Текст с вопросами

- **Ученик видит:** короткий текст: слова открываются с переводом, фразы озвучены, перевод по кнопке; 2–3 вопроса.
- **Данные:** `sentences`, `questions` (как `choose`), `glossary?`, `findTense?` (→ `tap`).
- **Проверка:** вопросы — как `choose`; на экзамене текст перед глазами без перевода.
- **Реализация:** `features/text-reading` (`ReadingView`), алфавит `text` (`TextReader`), раздел «Тексты».

### `compose` — Сочинение о себе

- **Ученик видит:** тему и чек-лист (настоящее, прошедшее, будущее, вопрос, отрицание); пишет — чек-лист отмечается сам.
- **Проверка:** чек-лист — подсказка, а не оценка: проверяет только формы глаголов урока.
- **Реализация:** `features/composition-check`.

### `order` — Расставить по порядку

- **Ученик видит:** элементы вперемешку, расставляет; лучший результат запоминается.
- **Реализация:** алфавит `order` (`AlphabetOrder`). Кандидат для мини-игр ивентов (порядок реплик в диалоге).

### `tiles` — Собрать фразу из плиток (план)

- **Ученик видит:** русскую фразу (или звук) и плитки-слова, среди них 1–2 лишних (другая форма того же глагола).
- **Данные:** как `translate`/`dictation`; лишние плитки — явно (`decoys`), формы не генерируются.
- **Проверка:** порядок плиток = одна из верных фраз; местоимение необязательно.
- **Роль:** лёгкий уровень письма — для `translate` и `dictation`.

### `shadow` — Послушать и повторить (план)

- **Ученик видит:** греческую фразу с озвучкой; слушает, повторяет вслух (можно медленнее).
- **Проверка:** самопроверка; с распознаванием — сравнение с фразой, неточность в ударении не считается ошибкой.
- **Роль:** лёгкий уровень говорения; в Кампании — «Повторите за Анной» к репликам главы.

### `readaloud` — Прочитать вслух (план)

- **Ученик видит:** греческую фразу без озвучки; читает вслух, потом слышит образец.
- **Проверка:** самопроверка; с распознаванием — автоматически.
- **Роль:** средний уровень говорения: опора — текст перед глазами, но звук ученик строит сам.

## Не задания (шаги-объяснения)

Не проверяются, засчитываются по «Дальше»: объяснение шага Истории, теория урока, таблицы глаголов (`verbs`),
новые буквы (`letters`), фразы темы, слова урока, «Любопытно» / рассказ кота. В Ежедневных их нет, в Ивентах —
только рассказ кота к теме.

## Открытые вопросы

1. **Где не хватает уровней.** Матрица навыков выше задаёт, какой тип стоит в какой клетке; у `tap` и `text` уровни
   различаются вариантом (с числом слов или без, с переводом или без) — это нужно сделать.
2. **«Показать ответ» в Ежедневных и Ивентах.** Засчитывать день, если ответ показан? Предложение: день закрыт, но без «звезды».
3. **Реестр в коде.** Один модуль, где у каждого id — тип данных, проверка, рендер для каждого уровня и список режимов;
   матрица этого документа генерируется из него скриптом.
